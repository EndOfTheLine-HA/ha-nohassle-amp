# v0.1.0: No Hassle AV Amplifier

First release. A 6-zone Monoprice-protocol amplifier integration with bass, treble
and balance on every zone, under its own domain `nohassle_amp`.

- Media player per zone, tone-control sliders, and the save and restore state
  services (`nohassle_amp.snapshot`, `nohassle_amp.restore`).
- **Import the existing amplifier** from the Monoprice integration (the built-in
  one, No Hassle AV 0.2.x or ha-monoprice-tone-controls): every entity ID, history,
  custom name, area, disabled zone and input name is kept. Make a full backup first.
- The serial port is released explicitly when the amplifier unloads or moves.

Do not run two integrations on one amplifier. Requires Home Assistant 2026.9.4 or
newer.
