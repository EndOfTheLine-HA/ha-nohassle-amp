# v0.2.0: the import from Monoprice is gone

## Changes

- **Removed:** the import of an amplifier set up under the `monoprice` domain.
  Nothing in this integration now reads, moves or removes another integration's
  config entries, devices or entities. The setup form is a single step.
- A warning in the log if an amplifier entry still carries the marker of a 0.1.0
  import that did not finish. See Upgrading.
- The zones, tone controls and services are unchanged.

## Upgrading

Update No Hassle AV Amplifier in HACS and restart Home Assistant. An amplifier whose
import to 0.1.0 finished keeps its entity IDs, names and history.

Before updating, check that the amplifier and its entities work. 0.2.0 cannot finish
an import that was interrupted. If the log says an import may not have finished,
install 0.1.0, restart, then update again.

If your amplifier is still under the Monoprice integration, see "Moving from the
Monoprice integration" in the README.
